# EVA01 Obsidian

The EVA01 theme uses the desktop palette: dark violet backgrounds, lavender
text, purple controls, restrained lime links and active icons, blue/amber/mint
syntax colors, and rounded controls. Markdown formatting, file layout, editor
font preferences and plugins are preserved.

Installed and selected in the existing vault's `.obsidian/themes/EVA01` folder.
The original appearance.json is backed up with the other EVA01 app backups.
Open/reopen Obsidian to load the selected theme. On another vault, copy the
EVA01 folder to `.obsidian/themes/` and select EVA01 in Settings → Appearance.

The backup repository stores only the theme and appearance preferences; vault
notes, attachments, workspaces and plugin/account data are not uploaded.

https://obsidian.md/help/themes
